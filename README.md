# Formulário de Cadastro

Formulário de cadastro desenvolvido em HTML e CSS, com campos organizados por seções (Dados Gerais, Endereço e Fale Conosco) usando `<fieldset>` e `<legend>` para agrupar informações relacionadas.

## O que foi praticado

- Estruturação semântica de formulários com `fieldset`, `legend`, `label` e atributos `name`/`id`
- Uso de tipos de input adequados (`text`, `date`) e atributos de validação (`minlength`, `maxlength`)
- Estilização com CSS puro: variáveis de cor, estados de foco/hover, grid para campos lado a lado e responsividade para telas menores

## Arquivos

- `formulario.html` — estrutura do formulário
- `estilo.css` — estilização visual
